## 🚀 Project Overview

본 프로젝트는 Next.js 기반의 풀스택 웹 애플리케이션으로,  
프론트엔드와 백엔드를 단일 코드베이스에서 구성한 ToDo 서비스입니다.

포트폴리오 목적의 프로젝트로,  
기능의 복잡도보다는 **코드 구조, 기술 선택, 개발 성향**을 보여주는 데 중점을 두었습니다.

프로젝트 관련 상세 문서는 [Wiki](https://github.com/im-pine/ToDoToDo/wiki)를 참조해 주세요.
